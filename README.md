# Solcon Extracion Utility Project- Frontend


This project follows a clean architecture model to ensure scalability and maintainability.

---


## 🚀 **Project Overview**
- **UI Framework:** AngularJS
- **Backend:** Spring Boot
- **Database:** PostgreSQL


---

## 📂 **Folder Structure**
The project follows a modular and scalable folder structure:


---

## 🗂️ **Folder Purpose**
| Folder | Purpose                                                      |
|--------|--------------------------------------------------------------|
| **src/app/components** | Reusable components                                          |
| **src/app/services** | Business logic and API handling                              |
| **src/app/models** | TypeScript models for data consistency, Data Models          |
| **src/app/utils** | Utility functions (like data formatting, calculations, etc.) |
| **src/assets** | Static files such as images, fonts, and icons                |
| **src/environments** | Configuration for different environments (dev and prod)      |
| **src/styles** | Global CSS/SCSS styles                                       |
